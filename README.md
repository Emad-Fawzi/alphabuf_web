# AlphaBuf — محرك فحص البورصة المصرية (نسخة الويب)

نسخة FastAPI + فرونت إند حديث، بديلة لنسخة Streamlit. نفس منطق التحليل والمصادر كله،
الفرق الوحيد هو طريقة العرض: API بيرجّع JSON، والفرونت إند (HTML/CSS/JS خام، من غير
build step) بيستهلكه بـ fetch() من المتصفح مباشرة - فالفلترة والترتيب بيحصلوا فورًا
من غير أي رحلة للسيرفر.

## التشغيل محلياً

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

افتح `http://localhost:8000` في المتصفح. الفرونت إند بيتقدّم من نفس السيرفر (مفيش
حاجة تشغيل تانية أو بورت تاني).

المفاتيح (اختيارية - الأداة شغالة من غيرها، بس ميزة الأخبار بالـ AI محتاجاها):
انسخ `backend/.env.example` لـ `backend/.env` وحط مفاتيحك.

## نشر الموقع مجاناً بدون شراء دومين (Render)

ملف `render.yaml` مجهّز بإعدادات الخدمة. الدومين المدفوع غير مطلوب: بعد النشر سيعطيك Render رابطاً مجانياً بصيغة `https://اسم-الخدمة.onrender.com`.

1. أنشئ حساباً على GitHub، ثم أنشئ Repository جديداً. ارفع محتويات المشروع كاملة إلى جذر المستودع: `backend/` و`frontend/` و`render.yaml` و`README.md`.
2. تأكد قبل الرفع أن ملفات الأسرار غير مضافة: لا ترفع `backend/.env` ولا مفاتيح API. ملفات الكاش `scan_cache.json` و`scan_history.json` و`news_sentiment_cache.json` محلية ومهملة بواسطة Git.
3. أنشئ حساباً على Render واربطه بـ GitHub.
4. من لوحة Render اختر **New → Blueprint**، ثم اختر مستودع GitHub الذي رفعته. سيقرأ Render ملف `render.yaml` ويعرض الخدمة `alphabuf-egx`.
5. اختر **Apply** أو **Deploy** وانتظر انتهاء Build وDeploy. أول تثبيت قد يستغرق عدة دقائق بسبب مكتبات التحليل.
6. افتح رابط `onrender.com` الذي يظهر في لوحة الخدمة. لا يلزم شراء دومين أو إعداد DNS أو تشغيل الفرونت إند منفصلاً.
7. اختبر أن الصفحة تفتح، ثم افتح `/api/health` على نفس الدومين؛ المتوقع أن ترى `status: ok` و`total_tickers: 229` وفق مرجع الأسهم المتداولة النشطة وقت آخر مراجعة.
8. إذا أردت تحليل الأخبار بالـ AI، أضف المفاتيح اختيارياً من **Environment → Add Environment Variable** داخل Render: `GEMINI_API_KEY` أو `OPENROUTER_API_KEY` أو `GROQ_API_KEY`. لا تضعها في ملفات الواجهة أو GitHub.

### ملاحظات مهمة عن الخطة المجانية

- الخدمات المجانية قد تدخل وضع السكون عند عدم الاستخدام، لذلك أول زيارة بعد فترة خمول قد تتأخر حتى يستيقظ السيرفر. سيبقى الموقع على رابط Render، لكن الأداء ليس كاستضافة دائمة.
- أول فحص للسوق طويل لأنه يجلب البيانات من مزودين خارجيين. الخطة المجانية مناسبة للتجربة، وليست ضماناً للتوافر أو سرعة الفحص.
- مساحة القرص في الخدمة المجانية مؤقتة؛ ملفات `scan_cache.json` و`scan_history.json` قد تختفي بعد إعادة تشغيل أو نشر جديد. إذا أردت الاحتفاظ بتاريخ مضمون على المدى الطويل، ستحتاج قاعدة بيانات دائمة مثل PostgreSQL أو تخزيناً دائماً توفره الخطة المستخدمة.
- الأسعار والحصص وشروط الخطة المجانية تتغير؛ راجع ما تعرضه لوحة Render وقت إنشاء الخدمة.
- كل تحديث تدفعه إلى GitHub يعيد النشر تلقائياً إذا تركت Auto-Deploy مفعلاً.

## هيكل المشروع

```
alphabuf_web/
├── backend/            FastAPI
│   ├── main.py         نقاط النهاية (scan, stock news, macro, excel export)
│   ├── config.py       قائمة الأسهم النشطة (229 رمزاً عند آخر مراجعة)
│   ├── utils/          secrets (env vars), cache (TTL)، provider_health (تبريد المصادر الفاشلة)
│   ├── data_sources/   mubasher.info (أساسي)، stockanalysis.com/investing.com (باكاب)، yfinance (آخر ملاذ)
│   ├── analysis/       المحرك الفني (RSI, MACD, MFI, SMA...)
│   ├── news/           سلسلة AI (Gemini→OpenRouter→Groq) + تجميع الأخبار
│   ├── macro/          أسعار الذهب/الفضة/الدولار + أخبار الأسواق
│   └── ui/excel_export.py
└── frontend/           HTML/CSS/JS خام (طابع محطة تداول داكن، خط IBM Plex)
```

## ملحوظات مهمة

- **investing.com معطّل افتراضياً** في طلب الفحص - فعّله بحذر لو حابب تجربه (أبطأ، وغير
  مستقر بالكامل).
- **mubasher.info بيدّي السعر والأساسيات والأخبار والإعلانات - مش الشموع التاريخية.**
  الرسم البياني بتاعه بيتحمّل بجافاسكريبت، فمفيش endpoint مكتشف بيدّي بيانات تاريخية.
  المؤشرات الفنية (RSI/MACD/MFI...) لسه معتمدة على yfinance/stockanalysis.com/investing.com.
- كل مصدر خارجي بيدخل "تبريد" 5 دقايق بعد أول فشل (على مستوى السيرفر كله، مش لكل مستخدم
  لوحده) عشان الطلبات ماتعلقش في انتظار مهلة شبكة كل مرة.
